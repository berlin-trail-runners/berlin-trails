# Berlin Trails

Trail running routes in and around Berlin, collected by Berlin Trail Runners —
a group of volunteers who spend their weekends finding out where the trails go.

Every route here has been run by the club. Each one is a GPX file you can load
into a watch or phone, and most also have a Komoot tour and some a Strava route.

For upcoming runs and events, see our
[Strava club page](https://www.strava.com/clubs/1572569).

## How to use a route

- **GPX** — download the file and import it into Garmin Connect, Coros, Suunto,
  or whatever you use. This is the copy that will always work, even if a
  platform disappears.
- **Komoot** — open in the app for turn-by-turn navigation and a surface
  breakdown.
- **Strava** — open in the app, or star it to sync to a device.

Many routes come in a long version and a shorter **early exit** variant that
cuts back to a station sooner. Look for pairs with the same name.

## Reading the table

| Column | Meaning |
|--------|---------|
| **km** | Approximate distance. |
| **Ascent** | Cumulative elevation gain in metres. |
| **EC** | **Elevation Coefficient** — cumulative ascent plus cumulative descent, divided by distance in km. It is a rough measure of how hilly a route feels: under 10 is largely flat, 20–40 is properly undulating, and anything above 50 is hill-repeat territory. |
| **Surface** | `Trail` is mostly unpaved, `Mixed` has meaningful road or path sections, `Park` is a short loop in a city park. |

## Adding a route

1. Export the GPX and name it using the existing convention:

   ```
   <km>km | +<ascent>m | <Area> | <Surface> | EC<coefficient> | <Name>.gpx
   ```

2. Put it in `routes/`.
3. Add an entry to `routes.json`, including the Komoot tour ID and Strava route
   ID if the route exists on those platforms (use `null` if not).
4. Regenerate the table:

   ```sh
   python3 generate_readme.py
   ```

   It refuses to run if `routes.json` and the files in `routes/` disagree, so a
   typo in a filename gets caught before it reaches the table.

5. Commit the GPX, `routes.json`, and `README.md` together.

`routes.json` is the source of truth for the table — edit it rather than the
generated rows, or your change will be overwritten on the next run.
